HYRULE TRAINING — INSTALLATION IPHONE

1. Décompresser cette archive.
2. Héberger ensemble index.html, manifest.webmanifest, service-worker.js et les 3 icônes sur un site HTTPS (ex. GitHub Pages).
3. Ouvrir l’adresse HTTPS dans Safari sur l’iPhone de Lauriane.
4. Appuyer sur Partager > Sur l’écran d’accueil > Ajouter.
5. Ouvrir une première fois en ligne pour préparer le mode hors connexion.

GITHUB PAGES (exemple)
- Créer un dépôt GitHub public, par exemple hyrule-training.
- Téléverser le contenu du dossier à la racine du dépôt.
- Settings > Pages > Deploy from a branch > main / (root) > Save.
- Attendre la publication puis ouvrir l’URL indiquée par GitHub Pages.

ATTENTION
Les données sont enregistrées localement sur l’iPhone. Utiliser Exporter mes données régulièrement.
Un changement de navigateur, une suppression de l’application ou des données du site peut faire perdre l’historique.
Les anciennes données d’un fichier HTML local ne sont pas transférées automatiquement.
